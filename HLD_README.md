## The question is how do we generate the unique ID in the distributed system?
    why not we choosen the UUID v4 , v7 or v8 
        v4 - these unique Ids are totally random. PROS = Uniqueness, Cons = Issued with the table grows with B-tree index, index fragment
        v7 - they are unique ids but at starting they are sorted , Cons = long size .. 128 bits size same as v4
        v8 - is also like the same with custom logic 
    There will be two ways to do this - either we will choose the snowfalke algo or zookeeper of apache's

# How this zookeeper and snowflake? works 

    => Snowflake - Snowflake algorithm generates the unique ID with the following components:
        - TimeStamp: the timestamp indicates when it was generated
        - NodeId/ MachineId: a unique identifier generated by the node/machine every machine has their own unique id
        - Step: A counter that increments for the each Id, within the same timestamp
